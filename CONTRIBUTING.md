# Contributing to Travel App CI/CD Pipeline

Thank you for your interest in contributing to this project! Here's how you can help:

## How to Contribute

1. **Fork the Repository** — Click the "Fork" button on GitHub.
2. **Clone Your Fork** — `git clone https://github.com/YOUR_USERNAME/70-travel-app-deploy-with-cicd.git`
3. **Create a Feature Branch** — `git checkout -b feature/your-feature-name`
4. **Make Your Changes** — Follow the existing code style and conventions.
5. **Test Locally** — Run `docker compose up -d --build` and verify your changes.
6. **Commit with a Clear Message** — `git commit -m "feat: add your feature description"`
7. **Push to Your Fork** — `git push origin feature/your-feature-name`
8. **Open a Pull Request** — Submit a PR against the `main` branch with a clear description.

## Guidelines

- Follow existing code formatting and naming conventions.
- Test all Docker Compose changes locally before submitting.
- Keep commits focused and atomic.
- Update documentation if your changes affect usage or configuration.

## Reporting Issues

Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md) or [feature request template](.github/ISSUE_TEMPLATE/feature_request.md) when opening issues.
